# Repo agent guide

## Repo-specific workflow

When working in this repo, the agent may proceed without asking for permission to make changes, continue to the next step, commit, or push.

Stage and commit only the agent's own changes. Do not include unrelated user changes in the same commit.

## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five-label triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. Read `GLOSSARY.md` at the repo root and `docs/adr/`. See `docs/agents/domain.md`.
